# DeepFish

国际象棋复盘工具。Stockfish 算棋，DeepSeek 把每一步讲成人话。


---

## 先说清楚：代码基本上都是 AI 写的

这个仓库是这么磨出来的 —— 我提要求，AI 写，我拿去复盘自己的棋，哪句讲得不对就回来追问，
然后改。`src/position.js` 里那堆纯函数、前端几百行 DOM 操作、还有那一千两百多项测试，
绝大部分是 AI 出的活。

我干的事主要是三件：

- 想清楚要什么、以及**不要**什么（比如"不要让模型自己算分数"就是我说死的）
- 真拿它复盘，发现讲错了就带着棋谱回来定位是哪一步、哪一句
- 看不懂的地方问到底，不问明白不往下走

所以你会看到满屏的中文注释，它们记的是"这里为什么非得这么写"。

如果你也在用 AI 写东西，这个仓库可能比一个"标准开源项目"更值得看：
它记的不是高手怎么写代码，而是一个不会写代码的人，带着 AI 能把一个想法磨成什么样、
中间会掉进哪些坑。

---

## 这个项目只认一条规矩

所有设计都围着它转：

> 引擎和代码负责**「是什么」** —— 该走哪步、前后几分、谁在盯着谁、这一步把谁的保护改了。
> 模型只负责**「为什么」** —— 把它讲成人话。
>
> 单子里所有的数字、格子关系、前后变化，都是引擎输出、或者代码按规则复算出来的。
> **模型一个字都不许自己产生。** 讲不清的地方，宁可让它说"我看不出来"。

这条不是一开始就想好的，是被逼出来的。

改到后来，绝大部分 bug 都是"模型讲错了"，但查下去十次有九次根因在我们这边 ——
要么是**没给它材料**，要么是**给的材料它能读反**。举三个真的例子（都是真跑出来的）：

| 它说了什么 | 查下去发现 |
|---|---|
|样例一第九步，白方Qd2， "d2 的后和 f4 的象一起盯住了 d6" | 后根本看不到 d6。真相是：那一步是**安静着法**，我们一个字都没喂，它只能自己推格子关系 |
| 把引擎变化线里的**第 5 手**说成"眼下的威胁" | PV 给了，但从没说"这是假想线，只有第 1 手是现在能走的" |
|样例三第五十步，白方Kh5， "白王就能 Kxh6 吃掉 h6 的兵" | 材料里根本没提那个兵 —— 因为那格被 g7 守着，`Kxh6` 规则上不合法。**看着能吃、材料沉默**，它就替你吃了 |

想改这个项目的话，**先读 [`项目总结.md`](项目总结.md)**。那份讲设计、讲边界、讲十个坑的根因；
这份 README 只讲"怎么跑、怎么改、怎么自检"。

## 跑起来

### 1. 装 Node.js

去 <https://nodejs.org/> 装 LTS 版，然后在项目目录里跑一次：

```bash
npm install
```

### 2. 放一个 Stockfish 引擎

**`stockfish/` 是 gitignore 的**（那个 exe 有 100MB 左右，不进版本库），
所以换一台机器一定要重新放：

1. 去 <https://stockfishchess.org/download/> 下 Windows x86-64 版
2. 解压，把 exe 丢进项目的 `stockfish/` 目录
3. 文件名保持 `stockfish-windows-x86-64-universal.exe`

想用自己的引擎（别的版本、别的路径）也行，在 `.env` 里写 `STOCKFISH_PATH=...`。

**不放也能开。** 服务器启动时会打一段黄字警告，界面里只有"算棋"那块用不了，
看棋谱、讲棋都照常。

### 3. 配 DeepSeek 密钥（可选）

不配完全能用 —— 算棋、曲线、复盘都在，只是少了"让 DeepSeek 讲讲"。

1. 去 <https://platform.deepseek.com/api_keys> 申请一把
2. 把 `.env.example` 复制成 `.env`，在 `DEEPSEEK_API_KEY=` 后面贴上
3. **不用重启**，刷新页面就是新的
4. 用一次消耗的token极少，几乎不花钱

（后端每次请求都会重新看一眼 `.env` 的修改时间，所以存盘即生效。
这个设计的由来写在 `src/llm.js` 里：原来只在启动时读一次，后果是"填了密钥却怎么刷新都不生效、
屏幕上还什么都不说"。）

### 4. 双击 `start.bat`

它会检查 Node 和依赖、起服务器，等 `/api/health` 通了再自动帮你开浏览器。

**那个黑窗口就是服务器本体，关掉它 = 关掉服务。**

手动起也行：`npm start`，然后开 <http://localhost:3000>。

> `start.bat` 有两个硬约束：**纯 ASCII + CRLF 换行**。
> 原因写在文件头的注释里 —— 中文进批处理会让 cmd 的行边界错乱，
> 后续所有行都当命令执行。仓库里那个 `start.bat.broken.bak` 就是坏掉的样本，留着当反面教材。

## 能干什么

| 功能 | 说明 |
|---|---|
| 载入棋谱 | 粘 PGN，或者用内置示例：三个小示例（愚人将杀 / 学者将杀 / 歌剧院之局）+ 三个真对局（样例一 / 二 / 三，鼠标停上去能看到各自是什么棋、该看哪一步） |
| 翻页复盘 | 开局 / 上一步 / 下一步 / 结尾，键盘 ←→ Home End，`F` 翻转棋盘 |
| 让鳕鱼分析 | 推荐着法 + 评分 + 候选路线，棋盘上画箭头 |
| 四个显示开关 | 局势条 / 评估曲线 / 每步评分 / 推荐箭头，随开随关 |
| 吃子栏 | 棋盘下面列双方各吃了哪些子，在吃子赚了的那一方标出分差。纯子力账，和引擎无关 |
| 让 DeepSeek 讲讲 | 把当前这一步讲成人话；结尾会多写一行「要点」当这盘棋的记忆（换棋谱清空） |
| 直接在棋盘上走棋 | 走出来的着法记成棋谱的**支线**，可悔棋、可清空、可导出成标准 PGN 变着 |
| 读自带评注的棋谱 | 认得出 lichess 的 `[%eval]` / `[%clk]`，判评（?! ? ??）标在着法列表上 |

## 改完代码怎么自检

```bash
npm test            # 四套：不需要服务器、不需要密钥、不花钱
npm run test:llm    # DeepSeek 那条线（本地假服务器，不花钱、不要真密钥）
npm run test:ui     # 把真实网页在 jsdom 里跑一遍（**需要服务器在跑**）
npm run test:all    # 全跑
npm run verify:live # 打一次真的 DeepSeek（配了密钥才有意义，会花几分钱）
```

| 检查 | 管什么 | 项数 |
|---|---|---|
| `verify-pgn.js` | 棋谱解析：带评注的棋谱、无评注 + 升变将杀、变着、NAG、FEN 头、畸形输入、**前后端 chess.js 副本字节一致** | 121 |
| `verify-timeline.js` | 棋子身份时间线：吃子、易位、吃过路兵、升变、坐标翻转 | 56 |
| `verify-engine.js` | 引擎层：UCI 握手、黄金着法、分数视角翻转、将杀、并发队列 | 32 |
| `verify-eval.js` | 评估层：分数归一化、格式化、`/api/evaluate` 批量接口 | 58 |
| `verify-llm.js` | 讲棋那条线：配置、错误分类（401/402/429/超时/断网）、重试、提示词组装、假 DeepSeek 端到端 —— **每条踩过的坑都有断言** | 435 |
| `verify-dom.js` | 真实网页跑在 jsdom 里：棋盘、翻页、分析面板、评注、曲线、局势条、走棋支线、导出、讲解、多轮记忆、吃子栏、样例按钮 | 523 |

一共 **1225 项断言**。

服务器没在跑的时候 `verify-eval.js` 会跳过 16 项，总数显示 1209 —— 这是设计如此，不是坏了。

## 密钥是怎么保证不跑出去的

一句话：**浏览器从头到尾没见过密钥，它只跟 `localhost` 说话。**

```
浏览器  ──►  本机后端（密钥只在这台机器、这个进程的内存里）  ──HTTPS──►  api.deepseek.com
```

`public/` 里翻遍都找不到密钥，也没有任何一行直连 DeepSeek 的代码 —— 它只请求 `/api/*`。
密钥只出现在一个地方：后端构造请求头的那一行 `Authorization: Bearer ***`。

另外几道闸门（都在代码里，改的时候别拆）：

- `.env` 被 `.gitignore` 挡在版本库外面 —— 这是它存在的唯一理由
- 出站只走**请求头**，不走 URL，所以密钥不会留在任何代理的访问日志里
- 上游报错回显会被 `scrubSecrets()` 擦一遍 —— 防的是"你换成自建中转之后，
  网关在 4xx 里把你的 `Authorization` 头原样吐回来"
- 给前端的接口（`/api/llm`、`/api/health`、报错体）**结构上就没有**密钥字段，
  只给"配没配""多长""打码预览"（`sk-abc****7890` 这种）

这些是实测过的，不是照注释抄的：把真密钥读进内存去搜六个 HTTP 出口的原始响应体，
一个都搜不到；另有一个 `verify-key-safety.js` 专门模拟"反向代理原样回显请求头"的最坏情况。
**细节写在 [`项目总结.md`](项目总结.md) 的"五之二、密钥是怎么关在这台机器里的"。**

## 常见问题

**点了"让鳕鱼分析"没反应**
`stockfish/` 里没有那个 exe。看启动时那段黄字警告，按上面第 2 步放好再重启。

**"让 DeepSeek 讲讲"按钮是灰的**
`.env` 里没配密钥，或者密钥无效。改完不用重启，刷新页面即可。
想确认密钥到底通不通，访问 `/api/llm?probe=1` —— 它会真发一个极小的请求去验，花费几乎为零。

**端口被占用（EADDRINUSE）**
已经有一个服务器在跑了（可能是一个没关掉的黑窗口）。先把它关掉。

**关掉黑窗口之后，会不会留下鳕鱼进程？**
不会。实测过：Node 被强杀之后，鳕鱼那边收到 stdin 关闭就自己退了。

**升级了 chess.js 之后要干什么？**
把 `node_modules/chess.js/dist/esm/chess.js` 重新拷到 `public/js/chess.js`。
`verify-pgn.js` 里有一项按**字节**比对这两份，忘了拷会当场报红。

⚠️ 顺手提醒：这件事还有个更容易中招的变体 —— **换行符**。
git 在 Windows 上默认会把文件转成 CRLF，而 npm 装出来的那份是 LF，
两边一转换字节就对不上了，报错看起来像"你副本拷错了"，其实根本不是。
所以 `.gitattributes` 里给这个文件写了 `-text`（禁止任何换行转换），
`start.bat` 则反过来钉成 `eol=crlf`。**这个文件别删。**
